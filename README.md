# radar.ino
*My first Arduino project: A sensor on a servo that tracks the distance of what is in front of it and at what angle printed on a LCD screen, along with a LED and buzzer system help that notify when a object is detected.

*This project helped refine my skills in hands on wiring and understanding how breadboards and certain components work. The one thing I did realize I have to work on more is understanding Arduino language. I had alot of outside help from the internet when it came to the coding portion in the IDE.

*Overall: I need to improve my coding skills and knowledge and continue improving on my already solid hands on skills.
